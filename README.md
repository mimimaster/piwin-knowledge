# piwin-knowledge-plugin

Standalone plugin extracted from `piwin` containing:
- `@piwin-knowledge/flashcards` (Markdown card store + FSRS scheduler + study round engine)
- `@piwin-knowledge/doc-rag` (Local folder document parser, chunker, and SQLite FTS5 retriever)
- `@piwin-knowledge/mcp-server` (Stdio MCP server + `plugin.json` + `skills/knowledge-study/SKILL.md`)

## Commands

```bash
pnpm install
pnpm typecheck
pnpm test
pnpm build
```
